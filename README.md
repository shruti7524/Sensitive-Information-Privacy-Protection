Sensitive Information Detection and Privacy Protection System

Project Overview

The Sensitive Information Detection and Privacy Protection System is a web-based application developed to identify and protect sensitive personal information present in documents and images.

The main objective of this project is to prevent accidental exposure of personal information while sharing files online. It allows users to detect sensitive information and protect selected details before downloading their files.

Objectives

- To identify sensitive information in uploaded files.
- To detect personal details such as email addresses, phone numbers and passwords.
- To provide privacy protection through masking and hiding selected information.
- To allow users to download protected files.
- To improve awareness about data privacy and security.

Technologies Used

- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: PHP
- Database: MySQL
- Local Server: XAMPP

Main Features

1. User Registration and Login
2. User Dashboard
3. File Upload
4. Sensitive Information Detection
5. Email, Phone Number and Password Detection
6. Selected Information Protection
7. Email Masking
8. Protected File Download
9. My Files Management
10. Activity Logs
11. Image Privacy Protection

Working of the System

1. The user registers and logs into the application.
2. The user uploads a document or supported file.
3. The system scans the file for sensitive information.
4. Detected information is displayed to the user.
5. The user selects the information that needs protection.
6. The system protects the selected information.
7. The user downloads the protected file.

Installation and Setup

1. Install XAMPP on your computer.

2. Copy the project folder into the "htdocs" directory.

3. Start Apache and MySQL from XAMPP Control Panel.

4. Open phpMyAdmin.

5. Create the required MySQL database and import the project database SQL file.

6. Configure the database connection details in the project.

7. Open the browser and visit:
   
   "http://localhost/privacy_protection/"

Project Purpose

This project was developed as an academic project to demonstrate the importance of personal data privacy and protection. It helps users understand the risks of sharing files containing sensitive information.
